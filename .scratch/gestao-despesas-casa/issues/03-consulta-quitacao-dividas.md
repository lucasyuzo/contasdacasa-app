# 03 — Consulta e Quitação de Dívidas

**What to build:** consultar Dívidas pendentes de um Morador e registrar Quitação (total ou parcial) numa Dívida
específica.

**Blocked by:** 02 — Despesa com Rateio Igual

**Status:** ready-for-agent

- [x] Listar Dívidas pendentes de um Morador como devedor
- [x] Listar Dívidas pendentes de um Morador como credor (Pagador)
- [x] Registrar Quitação (data, valor) numa Dívida específica
- [x] Suportar Quitação parcial (Dívida permanece com saldo residual) e total (Dívida quitada)
- [x] Quitação é sempre vinculada a uma Dívida específica — não existe saldo consolidado entre Moradores
