# 11 — Despesa Fixa e Recorrência

**What to build:** configurar uma Recorrência que gera Despesas Fixas automaticamente a cada período, com edição/skip individual de ocorrências.

**Blocked by:** 02 — Despesa com Rateio Igual

**Status:** ready-for-agent

- [ ] Marcar uma Despesa como Fixa e configurar uma Recorrência (valor, Rateio, Pagador, periodicidade)
- [ ] Recorrência gera automaticamente uma nova Despesa a cada período
- [ ] Uma ocorrência gerada pode ser editada individualmente sem alterar o template da Recorrência
- [ ] Uma ocorrência gerada pode ser pulada sem alterar o template da Recorrência
